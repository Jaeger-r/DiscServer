# Earth map data

These GeoJSON files come from [Natural Earth](https://www.naturalearthdata.com/),
the 1:110m cultural and physical vector datasets maintained in the
`nvkelso/natural-earth-vector` repository.

Natural Earth data is public domain. The files are kept in their original
GeoJSON form so the server can parse structured coastlines, rivers, populated
places and geographic-region labels (oceans, mountain ranges, plains, basins,
deserts, plateaus and island groups) instead of relying on hand-written map
data.
